● tcp-kai · v1.0.0

tcp-kai 1.0.0 — переезд на React и большой пакет улучшений

tcp-kai — десктопный клиент (Tauri) для запросов к NestJS-микросервисам по TCP: коллекция = микросервис, запрос = сохранённый cmd-паттерн, пак переменных = стенд (local/prod). Мажор 1.0.0 — это полностью переписанный на React фронтенд плюс новый CLI, импорт контрактов и «предохранители» для боевых стендов.

1.0.0 → 1.0.4 React 19 · Zustand · CodeMirror 6 + CLI tcp-kai (Rust) macOS · Tauri 2

1 · Фронтенд переписан со Svelte на React 19

под капотом

Весь UI мигрирован со Svelte/SvelteKit на React 19 + Vite 8. Внешне приложение то же, но стек стал стандартным и проще в поддержке.

  • Состояние — единый store на Zustand, разбитый на слайсы (collections, env, history, requests, runner, send, ui) и селекторы вместо самописных Svelte-сторов.
  • Редактор — Monaco заменён на CodeMirror 6 (@uiw/react-codemirror): легче, свой JSON-линт, подсветка {{vars}} и режим diff для истории.
  • Стили — Tailwind v4; иконки — lucide-react.
  • 20 компонентов, включая палитру команд (⌘P), сайдбар, переключатель стенда, диалоги окружения, раннер и импорт контрактов.

2 · Новое: CLI tcp-kai

главная фича релиза

Отдельный бинарь на Rust с общей с приложением базой. Тот же запрос, что и кнопка в GUI, но из терминала и скриптов — и он так же попадает в общую историю.

tcp-kai coordinator get-domains          # пак — применённый в GUI
tcp-kai coordinator get-domains -e local # тот же запрос на другой стенд
echo '{"limit":10}' | tcp-kai whois lookup --json | jq .response
tcp-kai notifier user-created --emit     # @EventPattern: ответ не ждём
КомандаЧто делает
tcp-kai <ms> <cmd>Отправить сохранённый запрос (шорткат к send)
tcp-kai ls [ms]Коллекции или запросы одной коллекции
tcp-kai envs <ms>Паки переменных (стенды) и их содержимое
tcp-kai history <ms> <cmd>Последние обмены из общей с GUI истории
tcp-kai import / parseНаполнить коллекцию из NestJS-контракта (см. ниже)
tcp-kai completions zshШелл-дополнения

Ключевые флаги

  • -e — разовый выбор стенда (состояние GUI не меняет)
  • -d / -f / stdin — тело поверх сохранённого
  • --var k=v — разовое значение переменной
  • --url host:port — мимо пака целиком
  • --json — в stdout только ответ (для jq)
  • --timeout — сек, 0 = ждать вечно (дефолт 60)
  • --no-history, -v — не писать в историю / трассировка

Секреты через sec

Токены не хранятся в базе, а приезжают из менеджера секретов sec по флагу --from-sec:

  • коллекция coordinator → проект tcp-kai-coordinator
  • пак prod → инстанс -e prod
  • тянутся только {{name}}, упомянутые в запросе
  • значения идут через stdout, не через argv
Установка бинаря — пункт нативного меню tcp-kai → Install CLI… (симлинк в /usr/local/bin, обновляется вместе с приложением). Для агентов есть скилл skills/tcp-kai/SKILL.md.

3 · Импорт контрактов из NestJS

GUI + CLI

Коллекцию можно наполнить прямо из *.contract.ts: парсер находит cmd-реестры (as const-объекты и enum с именем *Cmd*) и контроллеры с @MessagePattern.

tcp-kai parse  ../whois/src/contracts/cmd.contract.ts       # что нашлось, без базы
tcp-kai import whois ../whois/src/contracts/cmd.contract.ts --dry-run
tcp-kai import whois ../whois/src/contracts/cmd.contract.ts # создать новые запросы
  • Существующие запросы не трогаются; чьи cmd ушли из контракта — перечисляются, но не удаляются.
  • @deprecated по умолчанию пропускаются (--with-deprecated), лишние контейнеры фильтруются (--all снимает фильтр).
  • В GUI то же самое: ⌘P → коллекция → «Импортировать контракт», или просто перетащить .ts-файл в окно.

4 · Таймауты и предохранители для боевых стендов

таймауты

Настраиваемый лимит ожидания

Захардкоженный таймаут убран. Теперь лимит настраивается (дефолт 60 сек), 0 — ждать ответа вечно. В CLI — флаг --timeout.

prod-предохранитель

Подтверждение записи на прод

Если активный пак похож на боевой (prod/live/боев), а cmd похож на запись (create/update/delete/send…) — GUI требует явного подтверждения. Отдельно ловится не-JSON тело, которое транспорт молча превратил бы в data: null.

5 · Нативное меню и UI-полиш (1.0.1 – 1.0.4)

  • Нативное меню macOS: Install CLI…, Check for Updates…, Settings….
  • Кастомный тайтлбар с текущей коллекцией, окружением и историей.

  • Подсказки палитры перенесены в футер (в стиле Raycast); из реквест-бара убран переключатель event-паттерна.
  • Диалоги приведены к единому виду с sql-kai; действия пака вынесены в тулбар правой панели.
  • Новая иконка приложения под маску macOS 26 (без запечённых полей и силуэта).
